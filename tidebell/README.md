# Tidebell

An underwater exploration game. You pilot a small submersible from a sunlit reef down through a kelp forest, past a
wreck, over the edge of a wall and into the abyss. Seven tide bells sleep along the way; wake them and the sea sings
again.

## Play

- Open `index.html` (double-click works: it is one self-contained file with no network requests), or run
  `npm run serve` and open <http://127.0.0.1:5180/>.
- **W A S D** swim · **mouse** look (click to capture the pointer; drag or arrow keys also work) · **Space / C** rise /
  sink · **Shift** boost · **E** hold to wake a bell · **Q** sonar ping (marks the two nearest sleeping bells) ·
  **F** lamps · **Tab** logbook · **H** hide the HUD · **M** mute.
- Progress (bells and logbook) is saved in the browser. `__tb.reset()` in the console starts over.

The hull is rated to 45 m at first. Two bells raise that to 95 m; four remove the limit.

## Build

```
npm install
npm run assets    # Blender builds every model -> assets/tidebell.glb + assets/meta.json (about 10 s)
npm run build     # bundles src/ + three.js + the GLB into index.html
npm test          # unit tests for terrain, placement, physics and progression
```

### The film

`promo/tidebell-promo.mp4` is rendered from the game itself:

```
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P tools/blender/parade.py   # model-parade frames
node tools/promo.mjs            # needs Chrome and ffmpeg; add --stills for one frame per shot
```

`tools/promo.mjs` drives the built game in headless Chrome through `window.__tb`, one frame at a time: scripted
cameras, the real physics and HUD, a "blueprint" reveal built into the shaders, captions as DOM overlays, and a
soundtrack synthesised offline with the same recipes as the in-game audio. The numbers shown on screen are read from
the project at render time.

`npm run assets` expects Blender at `/Applications/Blender.app` (built with 5.2). Add `-- --preview` to also render a
picture of each model into `tools/blender/preview/`.

## How it is made

**Assets (Blender, `tools/blender/`).** All 48 models are generated by Python inside Blender: lofted fish, shark,
anglerfish, whale, manta, turtle and jellyfish; corals grown as branching skeletons through the Skin modifier; kelp,
sponges, anemones; rocks, a broken freighter, columns, a moon gate, the bells, vents and a whale skeleton. Each vertex
carries a painted colour, ray-cast ambient occlusion baked into it, and an emission mask in alpha. There are no
textures or downloaded assets.

**World (`src/terrain.js`, `src/scatter.js`).** The seabed is one analytic height function used for the mesh, for
collision and for placing about 18,000 instances of flora and rock by zone.

**Rendering (`src/shaders.js`, `src/gfx.js`).** Every surface uses one hand-written underwater shading model:
sunlight absorbed per colour channel with depth (red goes first, so the deep is blue until the lamps bring colour
back), animated caustics, headlamp cones, local glow lights, and distance fog that matches the open-water backdrop.
The frame is rendered to an HDR target, then a ray-marched light-shaft pass, bloom and a filmic tonemap are applied.
Fish schools and jellyfish are animated entirely in vertex shaders.

**Audio (`src/audio.js`).** Synthesised with the Web Audio API: water bed, a drone that sinks with depth, bells,
sonar and whale song.

## Layout

| Path | What it is |
|---|---|
| `index.html` | The built game |
| `src/` | Game source (rendering, world, life, player, HUD, audio, rules) |
| `tests/` | Unit tests for the pure logic modules |
| `tools/blender/` | Procedural asset pipeline |
| `tools/promo.mjs`, `tools/blender/parade.py` | Film renderer and its Blender model-parade pass |
| `promo/` | The rendered film, its score and preview stills |
| `assets/` | Generated GLB and metadata |
